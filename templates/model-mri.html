MODULE 01

MRI Imaging Analysis

Structural brain classification using classical Machine Learning algorithms.

Dataset & Preprocessing

We utilized the Mendeley MRI Dataset consisting of 6,400 brain scans. The original 4 classes (Non-Demented, Very Mild, Mild, Moderate) were mapped into a 3-class problem to align with the fusion model.

  • 0 (Normal): Non-Demented
  • 1 (Mild): Very Mild + Mild Demented
  • 2 (Moderate): Moderate Demented

Class Imbalance

Because the "Moderate" class had only 64 samples (out of 6,400), we applied class weighting techniques to prevent the model from ignoring the minority class.

Benchmarking

Three traditional classifiers were evaluated:

Algorithm F1-Score
K-Nearest Neighbors 0.7200
Support Vector Machine 0.8500
Random Forest (Winner) 0.8700
Why Random Forest?

Random Forest proved highly robust against the noisy pixel data of MRI scans and handled the class imbalance better than SVM, providing the highest recall for the Alzheimer's classes.
