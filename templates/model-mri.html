1. Concepts

Histogram of Oriented Gradients (HOG)

The HOG algorithm counts occurrences of gradient orientation in localized portions of an image. For this project, MRI scans are resized to 128x128 pixels to extract structural edges and shapes (like brain atrophy). This transforms the image into a mathematical vector.

2. Training & Benchmarking

We evaluated three classification algorithms using the same HOG features. Here is a breakdown of how each algorithm works:

Random Forest

An ensemble learning method that constructs a multitude of decision trees at training time and outputs the class that is the mode of the classes (classification) of the individual trees. It is robust to overfitting but can be slow.

Support Vector Machine (SVM)

A supervised learning model that analyzes data for classification by finding the optimal hyperplane (a line or plane) that best separates the different classes in a high-dimensional space. It is highly effective for image classification (HOG features).

K-Nearest Neighbors (KNN)

A non-parametric method that classifies data points based on the majority vote of their 'k' closest neighbors. It struggles with high-dimensional data (like HOG vectors), which explains its poor performance here.

3. Evaluation Metrics

How was the model evaluated?

  • GroupShuffleSplit by pHash: To prevent data leakage (e.g., images of the exact same patient in both train and test sets), we grouped near-duplicate images using Perceptual Hashing (pHash) before splitting.
  • Macro F1-Score: Because medical datasets often have class imbalances (e.g., more "Normal" than "Moderate"), we prioritized the Macro F1-Score. It calculates the F1-score for each class independently and averages them, ensuring the model isn't just good at predicting the majority class.
