PROJECT DEFINITION

The Silent Gap in Early Detection.

Alzheimer's disease affects over 55 million people globally. Despite its prevalence, traditional screening methods remain invasive, expensive, or insufficient to capture subtle early-stage cognitive decline.

01 — THE PROBLEM

Unimodal Limitations

Conventional diagnostic approaches rely heavily on isolated data sources. Magnetic Resonance Imaging (MRI) provides structural insights but can miss functional decline. Conversely, neuropsychological tests and speech analysis capture functional state but lack structural context. This lack of integration leads to high omission rates in initial evaluations.

02 — THE SOLUTION

Multimodal Late Fusion

NeuroFusion AI integrates structural brain data (MRI) with functional speech biomarkers (Audio) using a Late Fusion meta-classifier. By processing each modality independently and combining their probabilities, the system mirrors clinical diagnostic reasoning, providing a more robust and holistic screening tool.

03 — OBJECTIVES

What We Set Out to Achieve

General Objective

Develop a multimodal cognitive screening support system based on Machine Learning, combining MRI and voice analysis to reduce the omission rate in initial Alzheimer's evaluations.

Specific Objectives
  • 1. Audio Model: Train a classifier capable of detecting Alzheimer's vocal patterns (MFCCs, pauses) achieving an F1-Score > 0.80.
  • 2. MRI Model: Develop a structural classifier to identify cognitive stages (Normal, Mild, Moderate).
  • 3. Late Fusion: Implement a meta-classifier that optimally weights the probabilities of both modalities.
  • 4. Deployment: Expose the system via a REST API with a relational database (Supabase) and a web interface.
04 — SCOPE

What This System Is

  • ✓ An academic prototype for clinical screening support.
  • ✓ A pipeline built with open-source Machine Learning tools (Scikit-Learn).
  • ✓ A user-friendly web application for medical professionals.
05 — LIMITATIONS

What This System Isn't

  • ✗ A replacement for professional medical diagnosis.
  • ✗ A model trained on massive clinical cohorts (limited to public datasets like ADCeleb and Mendeley).
  • ✗ A system free of noise (YouTube audio contains background noise).
