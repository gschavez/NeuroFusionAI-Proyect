PROJECT DEFINITION

CRISP-ML Methodology

Our project follows the CRISP-ML standard to ensure a robust, scalable, and clinically relevant machine learning lifecycle.

01 — BUSINESS UNDERSTANDING

The Goal

Translate clinical needs into a Machine Learning problem. We identified the need for a non-invasive, multimodal screening tool to reduce false negatives in early Alzheimer's detection.

02 — DATA UNDERSTANDING

The Data

We utilized public datasets: Mendeley for 6,400 MRI images (Normal, Mild, Moderate, Very Mild) and ADCeLeb for speech data (extracted from YouTube).

03 — DATA PREPARATION

Feature Engineering

For audio, we extracted MFCCs, pitch, energy, ZCR, and Spectral Centroid. We applied Data Augmentation (adding white noise) to double the audio dataset and improve model robustness. For MRI, we used HOG.

04 — MODELING

Benchmarking

We trained Random Forest, SVM, and Logistic Regression. For audio, we implemented a Voting Classifier (Ensemble) which achieved the best F1-Score. For MRI, SVM was selected.

05 — EVALUATION

Metrics

In clinical screening, minimizing false negatives is critical. Therefore, model selection was based on the F1-Score and Recall of the Alzheimer's class, using Stratified K-Fold Cross-Validation.

06 — DEPLOYMENT

Architecture

A Flask REST API integrates the models, while Supabase (PostgreSQL) manages the clinical history. The system is deployed on Render.
