1. Concepts

MFCCs & Acoustic Features

We extract 19 distinct features per audio sample, including 13 Mel-Frequency Cepstral Coefficients (MFCCs), pitch, Zero-Crossing Rate (ZCR), RMS energy, and spectral centroids. These help identify pauses and vocal degradation associated with cognitive decline.

2. Training & Benchmarking

We tested individual algorithms and then combined them using an Ensemble approach to leverage their strengths:

Logistic Regression (LR)

A statistical model that uses a logistic function to model a binary dependent variable. It provides a good linear baseline but may struggle with complex, non-linear audio patterns.

Random Forest & SVM

Tree-based and margin-based algorithms, respectively. They perform better on complex data but still have limitations when handling the noise inherent in voice recordings.

Voting Classifier (Ensemble)

This is a meta-estimator that fits several base classifiers (LR, RF, SVM) and uses "soft voting" to predict the class label based on the argmax of the sums of the predicted probabilities. By combining them, we reduced variance and improved the F1-Score.

Algorithm Approx. F1-Score Status
Individual Models (Avg) ~0.74 Discarded
Voting Classifier (Ensemble) 0.80 Winner

3. Evaluation Metrics

How was the model evaluated?

  • Data Augmentation: To make the model robust against background noise, we augmented the training data by adding white noise, doubling the dataset size.
  • Stratified K-Fold: We ensured the split between training and testing maintained the same percentage of samples for each class (Normal, Mild, Moderate).
  • Focus on Recall (Alzheimer's class): In medical screening, a False Negative (missing a sick patient) is worse than a False Positive. The Ensemble model was chosen because it achieved the best balance of Precision and Recall (highest F1-Score).
